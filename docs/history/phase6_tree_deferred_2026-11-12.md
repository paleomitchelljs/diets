### Phase 6. Hierarchical tree model and fossil regime test (rewritten 2026-11-12)

**Outcome:** one hierarchical Bayesian model in which predator–prey size scaling is pooled along the tetrapod tree, fitted to extant data, and a test of which extant regime each fossil group resembles.

**What changed.** The four-step plan (6a descriptive audit, 6b reference model, 6c validation, 6d placement) is replaced by a single prompt; the old text is in `docs/history/phase6_superseded_2026-11-12.md`. Reasons: JM's talk is built on a tree-structured pooling model, not a clade regression with phylogeny as one random effect; the database cannot support several things the old plan asked for (7 individual pairs with a usable observation type, so no within-species slope; 169 vertebrate-prey rows in tiers A–C against 43,194 in D, so tier-cumulative fits show nothing before D). Design decisions (JM, 2026-11-12):

- The latent trait is the species intercept (expected ln prey mass at a reference predator mass). Slope and residual spread are regime-level.
- The core model has no time in it: each node is pooled toward its parent with one step per edge. Branch lengths enter as a tested extension through an exponent κ on edge length (κ = 0 unit edges, κ = 1 millions of years).
- The model is fitted to extant data. Fossils are not given their own regime; they are scored against each extant regime and a "none of the above" alternative. Whether theropods resemble crown birds is the question, not an assumption.
- Extant data are taken as broadly as possible (all tiers, after Phase 4b) and conclusions are tested by narrowing.
- Fitting evolutionary models across sets of most parsimonious trees, and ziphodonty, are verbal asides in the talk and are not part of this phase.

Known limits to report against: a unit-edge model is not invariant to taxon sampling (223 bird species, 3 crocodylians), so κ = 0 versus κ = 1 partly measures sampling density; the regime test is only as sharp as the regimes are distinct; about half the fossil pairs that Phase 3b can recover are fish prey, while the crown-bird reference is raptors and owls eating terrestrial vertebrates.

If no topology is available, or fewer than 90 percent of predator species with data are matched to it, stop and report. Fits that use branch lengths run only if Phase 5 delivered dated trees.
>
> **Step A, data and design (no model).** Build the analysis table: tetrapod predators, all tiers, every row with a predator mass and a prey mass or bracket. This broad set is the primary data; narrower sets are sensitivity fits. Make two prey-filter versions: vertebrate prey only (the bone filter) and all animal prey. Flag fish prey, juvenile predators, tier, and rows from OS-Prey. Report rows, species and studies by regime × observation type × tier, and the number of species with more than one observation type. List every fossil pair as usable with a point and interval, usable as a bracket, or excluded, with the reason.
>
> **Step B, extant model.** Write the model in `docs/MODEL_6.md` before fitting. The latent state x at every node is the intercept: expected ln prey mass at a stated reference predator mass. Root: x_root ~ Normal(mu, tau). Each child given its parent: x_child ~ Normal(θ_g + ρ_e·(x_parent − θ_g), v_e), where g is the regime painted on the edge. With edge length ℓ_e = t_e^κ (t_e in units of the regime's crown age), ρ_e = exp(−α_g ℓ_e) and v_e = σ²_g(1 − exp(−2α_g ℓ_e))/(2α_g), computed stably so that α_g → 0 gives a random walk exactly. At κ = 0 every edge has length one, so the model is a time-free nested model with per-step persistence ρ_g = exp(−α_g): ρ_g = 1 pools each node toward its parent only, ρ_g = 0 is an ordinary multilevel model around θ_g. At κ = 1 it is Brownian motion (α_g = 0) or Ornstein–Uhlenbeck. Regimes are painted on edges a priori and listed in the methods file: Mammalia, crown Aves, crown Crocodylia, non-snake Squamata, Serpentes, and a backbone regime for all other edges. There is no theropod regime. Hierarchy across regimes: θ_g ~ Normal(mu, tau); ln σ_g and α_g partially pooled. Prior on α_g: mode at zero, so that pooling toward the parent is the default and the data must move it; state the prior, what it implies for ρ_g at κ = 0 and for half-life at κ = 1. Observation model: ln prey_i ~ Normal(x_species[i] + β_g·(ln predator mass_i − reference) + δ_obstype[i], s_i), with ln s_i = γ0_g + γ1·(ln predator mass_i − reference). β_g and γ0_g are partially pooled across regimes; δ is shared across regimes with stomach contents as baseline. Use a non-centred parameterisation for node states. No likelihood weights, no subsampling. State every prior and run a prior predictive check. Fit, in this order: (1) κ = 0, the primary model; (2) a rank-nested check with no tree, species within genus within family within order within regime, one variance per rank; (3) κ = 1; (4) κ free with a prior that favours neither end.
>
> **Step C, simulation before real data.** On the real tree and design, simulate under a random walk, intermediate persistence and white noise, at κ = 0 and κ = 1, at least 20 replicates each; refit; report bias and interval coverage for α_g, σ_g, θ_g, β_g, δ and κ, how often the α posterior is distinguishable from its prior, and whether κ = 0 and κ = 1 can be told apart. Repeat the κ comparison after randomly dropping half the bird species, to show how much it depends on sampling density. State which regimes can support their own α. Then test the regime test: simulate fossil data at the real fossil tips, with the real mass intervals and brackets, under each candidate regime in turn, run Step D on them, and report how often the true regime is recovered and how often "none of the above" is chosen. Do not tune the model to pass.
>
> **Step D, regime test for fossils.** Fossil groups: non-avian theropods, stem birds, and each other fossil predator taxon with usable data. Fossil observation types map to stomach_content, pellet and direct_observation (combat associations); bite traces are excluded. Fossil predator masses are latent with priors from their database intervals; prey masses are latent with a prior from their interval where a point exists, interval-censored where only a bracket exists, and bounded above where only an upper bound exists. Candidates for each group: each extant regime's parameters painted on that group's edges, plus one "none of the above" candidate with its own θ drawn from Normal(mu, tau) and pooled α and σ. Test 1, on the tree: the log predictive density of the group's fossil data under each candidate, from the extant-only posterior, treating fossils that share ancestry jointly; report relative support with its Monte Carlo error. Test 2, tree-free: the predictive percentile of each fossil record against each regime's line and spread at its predator mass. Run both under κ = 0 and, if dated trees exist, κ = 1. Report results for each group and each taxon, say where the tests or the two values of κ disagree, and state plainly when the candidates are not distinguishable.
>
> **Step E, model ladder, joint fit and narrowing.** (1) Ladder: compare four models by held-out prediction, leaving out whole species and whole families: regimes only with no tree; nested without time (κ = 0); nested with time (κ = 1, α fixed at zero); κ = 1 with α free. Report the difference in expected log predictive density with its standard error at each step, and the posterior of κ from the free fit. (2) Joint fit: refit with fossils included as tips under the best-supported painting from Step D, and under the second-best where support is close; report node states along the theropod-to-bird path. (3) Narrowing, each as a full refit of the primary model with Step D repeated: vertebrate prey only against all animal prey; stomach contents only; fish prey removed; juvenile fossil predators removed; bracket-only fossils removed; tiers A–D only; tiers A–B only where any regime retains at least five species; OS-Prey removed; prior scale on α halved and doubled; a single α shared by all regimes. Report R-hat, effective sample size and divergences for every fit. Use one core per chain if chains hang at warm-up.
>
> **Step F, outputs.** `results/6_model.md`: regime lines with intervals; for each α_g the prior and posterior side by side, as ρ_g at κ = 0 and as a half-life in millions of years at κ = 1; the ladder table; the regime-test table for every fossil group and taxon; node states with intervals; what changes under each narrowing; agreement or disagreement with the Phase 5 results; and a list of conclusions the data do not support. Tidy exports for the site in `results/site/`: per-row points; per-species posterior median with a 10–90 percent prey-size interval (the spindles); regime lines; fossil points with mass intervals and regime support; node states; α prior and posterior draws; one file per fit (ladder rung or narrowing) with the same columns.
